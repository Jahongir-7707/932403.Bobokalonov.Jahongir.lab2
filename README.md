## Цель

Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

## Три способа подключения стилей

| Способ | Где | Что оформляет |
| --- | --- | --- |
| Внешний файл | `css/style.css`, подключён через `<link>` | все основные стили страницы |
| Внутренний блок | `<style>` в `<head>` | высота (`min-height: 48px`) и шрифт полей ввода |
| Inline-стиль | атрибут `style` у `<h1>` | `text-align: center` для заголовка |

Внутренний блок расположен после `<link>`: при равной специфичности побеждает правило, записанное ниже. Inline-стиль имеет более высокий приоритет, чем оба файла.

## CSS-переменные

Объявлены в `:root`. Основной цвет - серебристый `--silver: #c8ccd2`, акцент - чёрный `--accent: #000000`. Отдельно вынесены оттенки графита, градиент `--metal`, радиус скругления, шрифт и высота навигации, чтобы не дублировать значения по файлу.

## Позиционирование

| Значение | Элемент | Зачем |
| --- | --- | --- |
| `static` | `.content` | обычный поток документа |
| `relative` | `.skill-card` | база отсчёта для номера внутри карточки |
| `absolute` | `.skill-card__tag` | номер прижат к правому верхнему углу карточки |
| `fixed` | `.to-top` | кнопка «Наверх» закреплена в углу окна при прокрутке |
| `sticky` | `.site-nav`, `.sidebar` | меню и боковая панель прилипают при прокрутке |

## Состояния и псевдоклассы

- `.skill-card:hover` - длинная диагональная тень из нескольких `box-shadow` и сдвиг карточки.
- `.btn:focus` - свечение `box-shadow: 0 0 10px var(--silver)`.
- `.btn:hover`, `.btn:active` - тень и нажатие кнопки.
- `.nav-list a:hover`, `:active` - подсветка пункта меню и подчёркивание снизу.
- `input:focus`, `input:valid` - подсветка рамки поля.
- `a:visited`, `li:nth-child(odd)`, `li:last-child`, `::placeholder`, `::marker` - селекторы для типографики и списков.

## Оформление по варианту

Карточки навыков сделаны металлическими пластинами: градиент `linear-gradient(135deg, ...)` со светлыми и тёмными полосами имитирует шлифованный алюминий, при наведении появляется длинная тень. Тот же градиент использован у кнопки отправки формы.
